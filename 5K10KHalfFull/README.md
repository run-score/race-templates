# 5K10KHalfFull

Four-distance 5K / 10K / half / full marathon road race with a shared start and
finish. Copy this folder, open it in RunScore, set the race name and date, and
replace placeholder API keys in `Entries.INI` before any live upload.

Set a gun time per distance.

In-app help: `Readme.1.X.lst` (do not delete). Field purposes:
`Fields.1.X.lst`.
